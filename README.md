Requires API Mod Utilitools by Pentatrate

More up to date info about this mod can be found in the [beatblock modding discord server (invite)](https://discord.gg/VDvPUSCdGZ)
It has a dedicated post named `Quick Playtest` in the `ea-mods` forum

(And is also availiable for the Demo version of the game! Check out the post in `demo-mods`)

## How to install

1. Download zip:
	Either directly download the repository as a zip (**I recommend this**)

	[Download link](https://github.com/Pentatrate/quick-playtest/archive/refs/heads/main.zip)

	or download the "latest" release (The latest release may not have features added in later commits)

	![Commits Since Release](https://img.shields.io/github/commits-since/Pentatrate/quick-playtest/latest)

	![Screenshot to find releases](https://github.com/user-attachments/assets/2acbead3-fad3-476b-9525-43fb1d728cb6)

2. Unzip and place in `beatblock/Mods/` folder (where all the other mods are)

	**!!!Reminder!!!**: Make sure the mod.json file is in `beatblock/Mods/quick-playtest/mod.json` and **NOT** `beatblock/Mods/quick-playtest/quick-playtest/mod.json`

3. Relaunch modded beatblock
